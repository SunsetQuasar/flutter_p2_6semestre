# flutter_f

P2 – DESENVOLVIMENTO DE APLICATIVO MOBILE COM FLUTTER E FIREBASE

Windows:
 - Abrir um novo projeto Flutter padrão usando VSCode
 - Adicionar (e substituir) os arquivos padrão
 - `flutter clean`, `flutter pub get`, `flutter doctor`, etc
 - setup padrão de flutterfire usando esse [guia maravilhoso](https://andreunigran.github.io/aulas_mobile/aulas/aula15.html)
 - alterar link do banco de dados em `lib/services/db.dart`
